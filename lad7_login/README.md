## 📖 Giới thiệu (Introduction)
Dự án này là bài tập thực hành Lab 7, tập trung vào việc phát triển Frontend (Giao diện người dùng) và xử lý logic cơ bản cho chức năng Đăng nhập. Ứng dụng được xây dựng bằng Framework (Khung phần mềm) Flutter và ngôn ngữ lập trình Dart, đáp ứng các tiêu chuẩn về một ứng dụng di động hiện đại.

## 🚀 Các tính năng chính (Key Features)
* Xây dựng User Interface (Giao diện người dùng) trực quan, hiện đại cho màn hình đăng nhập.
* Thực hiện Input Validation (Xác thực dữ liệu đầu vào) cho các trường tài khoản và mật khẩu để đảm bảo tính chính xác trước khi gửi dữ liệu.
* Áp dụng State Management (Quản lý trạng thái) cơ bản khi người dùng tương tác với các nút bấm và trường nhập liệu.

## 💻 Yêu cầu hệ thống (Prerequisites)
Để chạy được Source code (Mã nguồn) này, máy tính của bạn cần cài đặt sẵn:
* **Flutter SDK (Bộ công cụ phát triển phần mềm Flutter):** Khuyến nghị sử dụng phiên bản ổn định (Stable) mới nhất.
* **IDE (Môi trường phát triển tích hợp):** Visual Studio Code, Android Studio hoặc IntelliJ IDEA.
* **Emulator (Trình giả lập)** hoặc thiết bị vật lý đã bật chế độ gỡ lỗi để kiểm thử ứng dụng.

## 🛠️ Hướng dẫn cài đặt và khởi chạy (Installation & Usage)

**Bước 1: Clone Repository (Sao chép kho lưu trữ)**
Mở Terminal (Cửa sổ dòng lệnh) và chạy lệnh sau để tải dự án về máy:
```bash
git clone [https://github.com/NNVHG/2224802010628_NguyenNgoVuHoangGia_flutter.git](https://github.com/NNVHG/2224802010628_NguyenNgoVuHoangGia_flutter.git)

```

**Bước 2: Di chuyển vào thư mục dự án (Navigate to Project Directory)**

```bash
cd 2224802010628_NguyenNgoVuHoangGia_flutter/lad7_login

```

**Bước 3: Cài đặt Dependencies (Thư viện phụ thuộc)**
Tải các thư viện cần thiết được khai báo trong dự án:

```bash
flutter pub get

```

**Bước 4: Khởi chạy ứng dụng (Run the Application)**
Đảm bảo rằng bạn đã mở Emulator (Trình giả lập) hoặc kết nối thiết bị thật, sau đó chạy lệnh:

```bash
flutter run

```

## 📂 Cấu trúc thư mục chính (Main Folder Structure)

* `lib/`: Chứa toàn bộ Source code (Mã nguồn) Dart của dự án.
* `main.dart`: Tệp tin khởi chạy chính của ứng dụng.


* `pubspec.yaml`: Tệp cấu hình chứa các Dependencies (Thư viện phụ thuộc) và Assets (Tài nguyên tĩnh như hình ảnh, font chữ).
